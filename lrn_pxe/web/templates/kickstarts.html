What is a Kickstart File?

A kickstart file is a plain-text script that tells the installer exactly how to set up a machine — no clicking, no prompts. It can define the language, keyboard, timezone, partitions, packages, user accounts, firewall rules, and more. Once associated with a boot image in the Menu Builder, machines that boot from that entry will install automatically.
