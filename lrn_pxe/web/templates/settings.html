Important Notes
Restart required: After changing DHCP or IP settings, restart the dnsmasq service from the Dashboard for changes to take effect.
One DHCP server per network: Only run this PXE server's DHCP if no other DHCP server is active on the same network segment. Conflicts cause connectivity issues.
ISO storage: ISOs are stored in /opt/lrn_pxe/isos/. Ensure sufficient disk space before uploading large images.

About LRN_PXE
Version: 1.0.0

Platform: Rocky Linux 9 / 10
Stack: dnsmasq · nginx · Flask · Bootstrap 5
